# Virtual X-ray

## 기능

- 3D 풀 트랙 스켈레톤 버츄얼 모델
- 방향키로 평행이동 가능
- (-) (+) 키로 확대 축소 가능
- C 버튼으로 콜리메이터 효과 온오프 가능

## 사용법

1. 배치파일 실행
2. 3D 모델 화면을 전체화면으로 켠 뒤, 빔 프로젝터로 벽에 쏘기
3. 수동 조정으로 몸에 잘 스키닝하기 (비율이 안 맞는 것은 어쩔 수 없음)
4. 가지고 놀기

## 주의

1. 어두워야 리얼하지만 어두울수록 인식은 안 됨.
2. 웹캠 위에 바로 덧씌우는 방식으로 수정하면, 빔 프로젝터를 쐈을 때 출력부와 입력부가 무한 순환하므로 지양할 것.
